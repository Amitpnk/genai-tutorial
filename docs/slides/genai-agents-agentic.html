Orientation

Where this starts

The words are on every CV. The answers aren’t.

Open any LinkedIn profile or résumé: Generative AI · AI Agents · Agentic AI. Then ask one plain question, and the room goes quiet.

Is ChatGPT an AI agent?

Sometimes yes, sometimes no — and the deciding factor isn’t the model.

How is this different from a Zapier automation?

Both call APIs and act without you. So what actually changed?

Is “AI agent” just another word for “agentic AI”?

The same person will use both in one sentence, meaning two different things.

None of these are trick questions — they are the subject. If you can answer all three in a sentence each by the end, the session did its job.

PART ONE

Generative AI

A model that produces content. Powerful, and more limited than it looks.

Generative AI

Definition

What generative means

Generative AI (Gen AI) is AI that can generate new content based on what it has learned and the instructions you give it.

  • Text — an email, an article, a summary, an answer to a question.
  • Code — Copilot turning “paginate this endpoint” into a working function.
  • Images — a picture from “a dog sitting on the moon.”
  • Audio — a new piece of music, or a voice reading your script.
  • Video — a clip generated from a written prompt.
Generative AI

Pipeline

From your prompt to new content

You give it an instruction. It runs that instruction against patterns learned from an enormous amount of text, and writes something that fits.

Ask for “microservices, explained to a beginner” and you get a fresh explanation, not a document it looked up. From here we stay with language models — and the next slide opens up that middle box.

What follows from that

Three limits, and they are structural

  1. No memory

    Every API call is independent. A "conversation" is you re-sending the history each turn; the model remembers nothing.

  2. No actions

    It emits text. It cannot read your database, call your API, or send an email — there is no mechanism by which it could.

  3. Hallucination

    Hallucination is about accuracy. The model generates a plausible continuation rather than retrieving a fact, so it produces confident text that happens to be false.

Everything in the next two parts of this session exists to work around one of the first three. Nothing works around the fourth — a wrong fact just becomes a wrong action faster.
Generative AI

Demo · lesson 00

The entire API surface is one request

# text in, text out. no memory, no tools, no loop.
response = client.messages.create(
    model="claude-opus-5",
    max_tokens=1000,
    messages=[{"role": "user", "content": "What is a token?"}],
)

# the reply is a LIST of typed blocks, not a string
# -> [TextBlock(type='text', text='A token is ...')]
Run this twice and the second call knows nothing about the first. Everything from here on is scaffolding around this one request.

PART TWO

AI Agents

Giving the model a way to affect the world — and keeping the switch in your hands.

AI Agents

Definition

What is an AI agent

An AI agent is a system that can hold a goal, decide what to do next, use tools, and keep acting until the goal is met.

Gen AI — generates an answer

You ask, it produces text. Everything that happens after that is still your job.

AI agent — takes action

You give it a goal. It works out the steps, runs them, and reacts to what comes back.

An AI Agent is a Gen AI-powered system that can reason, plan, use tools, and take actions autonomously to accomplish a goal.

In one line: a Gen AI–powered system that can reason, plan, use tools, and act to accomplish a goal. Hold on to the word system — the model is only one part of it.
AI Agents

Example — answering vs doing

“Find me a good hotel in Goa this weekend and book it.”

Gen AI replies

“Here are some good hotels in Goa…”

Genuinely useful. And every step that follows is still yours to do.

An agent works through it

  • Search for hotels
  • Compare price, rating, location
  • Check availability for the dates
  • Pick the best fit
  • Ask you to confirm
  • Make the booking
Not answering — doing. Note step five: it pauses for confirmation because you built that pause into the tool, not because the model chose to be careful.
AI Agents

Example — a coding agent

“Fix the login bug in my application.”

goal   fix the login bug in my application

  read the code       the session check runs before the password check
  edit the code       reorder the two checks
  run the tests       2 failed
  read the failures   the test fixture logs in twice
  edit the code       reset state between tests
  run the tests       all passed

done   here is the change, and why it works
Nobody wrote that sequence in advance. Each step was chosen after seeing the result of the last one — including the detour when the tests failed. That rhythm is what the rest of this part is about.
AI Agents

Demo · lesson 03

Watch the turns go past

user       Should I take a jacket in Pune today?
assistant  [tool_use] get_weather(location="Pune, MH")
user       [tool_result] 22 degrees celsius and clear
assistant  No jacket needed — it's 22C and clear.

Four turns, two API calls, one function executed by your code. The middle two lines are the entire difference between a chatbot and an agent.

Note the roles: tool results come back as a user message. From the model's side, your code is just another participant in the conversation.

PART THREE

Agentic AI

Handing over the control flow — deliberately, and less often than you'd think.

Agentic AI

Definition

What is an Agentic AI

Agentic AI takes a goal, makes a plan, uses tools, acts, looks at what came back, and adapts until the goal is met.

Goal + reasoning + planning + tools + actions + feedback.

That last term is the one that does the work. Without feedback you have a script; with it, the system can notice it was wrong and try something else.

Gen AI creates. AI agents act. Agentic AI orchestrates those actions toward a goal.
Agentic AI

Example

“Plan a trip to Goa for me.”

  • Work out what you actually need
  • Draft a plan for getting there
  • Search flights and hotels
  • Compare prices and options
  • Build an itinerary around them
  • Call the booking tools
  • Re-plan when something is unavailable
  • Hand you the finished plan
Seven is the one that matters. When the hotel is full, nobody told it what to do next — it decides, and the rest of the plan changes. That is the whole of “agentic” in one step.
Agentic AI

All three, in one kitchen

Ask three people for a cake

Gen AI

“Tell me how to make a cake.”

You get the recipe. You do the baking.

AI agent

“Make a cake.”

It follows the recipe, using the tools it has been given.

Agentic AI

“A birthday cake for 10 people, by 6 PM.”

  • Plan backwards from six
  • Check what's in the cupboard
  • Buy what's missing
  • Bake, taste, adjust
  • Deliver on time
Same kitchen, same recipe, same oven. What changes is how much of “what to do next” you handed over — and the third one is the only order you could give a colleague.
Agentic AI

The ladder

Four words people use interchangeably

In one line Example
AI Makes a prediction or a decision Flagging an email as spam
Gen AI Creates new content Writing the email
AI agent Performs a task using tools Searching and comparing hotels
Agentic AI Plans, acts, observes, and adapts toward a goal Planning and booking the whole trip
That is how the four terms get used in practice. The next slide sharpens the last one — “agentic” is not a fourth product you buy, it is a matter of degree.
Corrections

Summary

The three, side by side

Generative AI AI agent Agentic system
Core parts A model, and nothing else Model + tools + a loop you wrote Model + tools + planning and state — sometimes several agents
Action Generates content only Performs narrow tasks using tools Plans and executes multi-step work
Memory None Short-term — the history you re-send Longer-term — state your code keeps between runs
Autonomy Low — you drive every step Medium — it picks tools, you wrote the loop High — it picks the steps too
Fails by Confident wrong answers Wrong tool, bad arguments Looping, drifting, compounding errors
Example Write a story Book a flight Plan a whole holiday, visa included
Read two rows carefully. Memory is state your code stores and re-sends — no row of this table lives inside the model. And autonomy is not a setting; it is how much of the control flow you handed over.

Three words, three different things

Gen AI creates. AI agents act — through code you wrote. Agentic means the model, not you, decided the order of the steps.
