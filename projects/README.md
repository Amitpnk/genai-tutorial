# Capstone Projects

Each project is self-contained: its own README, its own entrypoint, its own
success criteria. Pick one after finishing the notebooks — or pick the one
closest to a problem you actually have, which is better.

| Project | Builds on | What makes it hard |
|---|---|---|
| [01 — Doc Q&A Bot](01-doc-qa-bot/) | Lessons 04, 05, 07 | Knowing when to refuse |
| [02 — Support Triage Agent](02-support-triage-agent/) | Lessons 02, 03, 06 | Routing decisions you can audit |
| [03 — Code Review Assistant](03-code-review-assistant/) | Lessons 03, 06, 08 | Signal-to-noise at scale |

Each has a "definition of done" you can measure. Ship against that, not
against how impressive the demo feels.
