# Solutions

Completed versions of the notebook exercises, one file per lesson, same
filenames as `notebooks/`.

Try the exercise first. The value is in the attempt — reading a solution to a
problem you have not struggled with produces recognition, not understanding.

When you do compare, look for *why* the solution differs, not just that it
does. Several exercises have more than one reasonable answer; the notes in
each solution flag where that is the case and what the tradeoff is.
